# TeenHub 🚀
*Por jóvenes, de jóvenes, para jóvenes.*

TeenHub es una aplicación multiplataforma (iOS, Android, Mac, Linux y Windows) diseñada exclusivamente para adolescentes de 10 a 21 años. Nuestro objetivo es transformar la vida diaria y el estudio en una experiencia colaborativa, ofreciendo un espacio seguro para manejar emociones, reducir el estrés académico y compartir talentos.

## ✨ Funciones Principales

* **Feeling Tags:** Selecciona y muestra tu estado emocional actual en tu perfil (Feliz, Estresado, Valiente, etc.) para que la comunidad sepa cómo te sientes. Tu foto de perfil incluye un marco dinámico que indica tu estado en línea.
* **Homework Collab & Leaderboard:** Ayuda a otros estudiantes con sus tareas y gana 3 XP por cada colaboración. Compite en el temporizador semanal; el primer lugar recibe un diseño de perfil dorado exclusivo.
* **Skill Swapper:** Un mercado de intercambio de habilidades. Ofrece lo que sabes hacer (ej. Matemáticas) a cambio de lo que necesitas (ej. Programación en Python). Realiza 200 intercambios para ganar el marco especial de "Trader".
* **Problem Sharer:** Un muro de apoyo donde puedes publicar situaciones difíciles y recibir consejos de la comunidad.
* **Desconexión Agendada:** Función de bienestar digital que limita las notificaciones nocturnas para prevenir la dependencia a las pantallas.

## 🛠️ Arquitectura y Tecnologías

* **Frontend:** React / TypeScript (Generado y estructurado para despliegue web).
* **Móvil (iOS/Android):** Capacitor (Ionic).
* **Escritorio (Mac/Linux/Windows):** Tauri / Electron.
* **Backend y Base de Datos:** Supabase.
* **Autenticación:** Integración de cuentas nativa con [Lucasta Hub](https://lucastahub.vercel.app/).

## 🔒 Seguridad y Privacidad

Diseñado con la seguridad como máxima prioridad:
* **Base de datos privada y encriptada:** Nadie tiene acceso a tus datos personales. No se permite el acceso a aplicaciones de terceros.
* **Protección de cuentas:** Soporte para contraseñas fuertes y Verificación en Dos Pasos (2FA) para prevenir hackeos.
* **Moderación:** Filtro automatizado de malas palabras y sistema de reputación basado en edad y likes para mantener un entorno seguro.
* **Recopilación mínima:** Solo se requiere un correo electrónico y contraseña para registrarse.
